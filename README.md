# homebrew-anirss

Homebrew tap for [anirss](https://github.com/marcusbandit/anirss).

## Install

```sh
brew install marcusbandit/anirss/anirss
```

Or, two-step:

```sh
brew tap marcusbandit/anirss
brew install anirss
```

Bleeding-edge from `main`:

```sh
brew install --HEAD marcusbandit/anirss/anirss
```
